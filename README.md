# Eboniee Events

## Description
A web application for an event planning business that allows users to view services and submit event inquiries. Request are then sent to a database for viewing. 

## Features
- Multiple pages
- Event services information
- Contact form
- Supabase database integration
- Responsive UI

## Technologies
- React
- React Router
- Supabase
- Netlify
- GitHub

## Setup Instructions
- Create Repo
- Create folders in VS code
- Add, Commit and Push to Repo
- Save code
- Create Database using Supabase
- Deploy Application using Netlify
- Record Demo Video
