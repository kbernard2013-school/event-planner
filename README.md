# Eboniee Events

## Description
A web application for an event planning business that allows users to view services and submit event inquiries.

## Features
- Multiple pages
- Event services information
- Contact form
- Supabase database integration
- Responsive UI

## Technologies
- React
- React Router
- Supabase
- Netlify
- GitHub
